# Data 공개 원칙

본 프로젝트는 화장품 제품정보, 전성분 정보, 과거 리뷰 데이터를 활용했습니다.

최종 연구 규모:

- Cream products: 231
- Historical reviews: 47,487
- Skin types: 7
- Product × Skin observations: 1,124

## 왜 원본 데이터를 올리지 않나요?

원본 크롤링 결과와 리뷰 텍스트 전체는 데이터 출처의 이용조건, 재배포 범위,
개인정보·저작권 가능성 및 Repository 용량을 고려해 공개하지 않습니다.

따라서 이 Repository는 다음을 공개합니다.

- 데이터 처리 방법
- 실제 전처리 Notebook
- Feature Engineering Notebook
- 검증 및 모델링 방법
- 집계된 최종 성능 결과

원본 데이터 없이도 프로젝트의 설계와 코드 구조를 검토할 수 있도록 구성했습니다.
